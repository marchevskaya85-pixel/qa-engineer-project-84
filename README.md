# Тестирование интернет-магазина

Учебный проект в рамках профессии «Инженер по тестированию» на платформе Hexlet. В ходе работы проведен полный цикл ручного тестирования веб-приложения интернет-магазина (первой и второй версий).

## Выполненные этапы и артефакты
* **Анализ требований (`requirements.yml`)** — изучение документации заказчика, разделение требований на функциональные, нефункциональные и неявные.
* **Тест-анализ и дизайн (`test-cases.yml`)** — разработка набора тест-кейсов для проверки ключевой функциональности магазина.
* **Проведение тестирования (`testing-report.yml`)** — прогон сценариев на первой версии приложения и фиксация статусов проверок.
* **Оформление дефектов (`bugreports.yml`, папка `assets/`)** — составление подробных баг-репортов по найденным ошибкам с приложением скриншотов.
* **Регрессионное тестирование (`regress-report.yml`)** — повторная проверка обновленной версии приложения, контроль исправления старых ошибок и фиксация новых регрессионных багов.
